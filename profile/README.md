# SAWStudio — mixer and edit suite on one console

SAWStudio keeps one named board on the desk: the live mixer buses, the take in front of you, and a short note the next editor can read. Extra sessions wait for their own title.

## Session Card

| Slice | What you do in SAWStudio | What remains |
|-------|------------------------|--------------|
| Arrival | Open SAWStudio and name today's console desk | A titled mix session |
| Focus | Keep only live buses on the SAWStudio board | A short mixer list |
| Check | Read SAWStudio live recording before a large edit | A confirmed take set |
| Handoff | Mark finished takes inside SAWStudio | A note for the next editor |

## How SAWStudio Sits

SAWStudio does not replace the hardware mixer, the tape deck, or the DAW you already keep for the same room. It sits beside them as a named console desk for one job: which mixer is live, which live recording still matches the edit suite, and what the next editor should read.

If two people share a studio PC, each keeps a SAWStudio style of their own. Extra sessions wait for their own title instead of crowding the live buses.

## Traffic Light

| Signal | On the SAWStudio board | What you do |
|--------|----------------------|-------------|
| Green | Named console, short live bus list | Continue the same mix session |
| Amber | Two sessions mixed on one mixer | Split the buses before a large edit |
| Red | No title, no note, takes unlabeled | Stop and name the console first |
| Clear | Handoff written, live buses few | Close SAWStudio and leave the console desk |

## Open Order

1. Open the last SAWStudio console desk, not a new empty mix session.
2. Read the mixer buses and the last handoff.
3. Finish one visible live recording pass inside SAWStudio.
4. Write what changed, then close with fewer unlabeled takes than you found.

| Home mix | Personal takes out of the studio console |
| Client night | Delivery files kept apart from rolling takes |

## After a Week

A week in SAWStudio is not a larger unlabeled take pile. It is the same title, a shorter live mixer, and a note that still makes sense while the session is still rolling. Take finished takes off the live set so the next visit starts on the console desk that is still open.

## Sign-off

- [ ] The SAWStudio workspace name is short enough to scan
- [ ] Only live buses sit on the mixer
- [ ] A second engineer can read the console handoff

## Field Note

SAWStudio is easier to trust when the console desk stays smaller than the unlabeled take pile it came from. Name the session, keep the live mixer, finish one visible edit, and write what changed.
